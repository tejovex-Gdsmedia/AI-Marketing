💳 Launchpad Wallet System

A comprehensive payment system for video generation with prepaid wallet credits

✨ Users prepay via wallet funds instead of real-time payment processing. Funds are deducted instantly when they generate videos, with automatic tracking of costs, commissions, and spending history.

System Overview

Commission Rate: 20% on top of API costs (configurable in wallet-service.ts)

User Wallet

Each user has a dedicated wallet balance. Add funds at any time and your balance is immediately available for video generation.

Instant Deduction

When you generate a video, the total cost (API + commission) is deducted from your wallet in real-time.

Transaction History

All credits and debits are recorded with detailed descriptions, allowing you to track spending and understand costs.

Cost Breakdown

Every video generation shows the API cost separately from your commission, so you see exactly what you're paying.

How It Works

1

Add Funds

User navigates to the Wallet section and adds funds (e.g., $100). Balance updates immediately.

2

Select Model & Generate

User selects a video model and starts generation. System calculates total cost: API cost + 20% commission.

3

Check Balance

System checks if wallet has sufficient balance. If yes, proceeds. If no, shows error and blocks generation.

4

Deduct & Record

Cost is deducted from wallet and a transaction record is created linking the video generation to the debit.

5

View History

User can view complete transaction history with timestamps, amounts, and descriptions.

Database Schema

Four main tables power the wallet system:

Wallet Table

model Wallet { id String @id @default(cuid()) userId String @unique balance Float @default(0) // Current available balance totalAdded Float @default(0) // Total funds added lifetime totalSpent Float @default(0) // Total funds spent lifetime createdAt DateTime @default(now()) updatedAt DateTime @updatedAt }

Transaction Table

model Transaction { id String @id @default(cuid()) userId String type String // "credit" or "debit" amount Float description String balanceBefore Float // Balance before this transaction balanceAfter Float // Balance after this transaction videoGenId String? // Link to video generation if debit createdAt DateTime @default(now()) }

VideoGeneration Table

model VideoGeneration { id String @id @default(cuid()) userId String modelId String // e.g., "kling-3.0" modelName String // e.g., "Kling 3.0" prompt String duration Int // In seconds apiCost Float // Provider's cost commission Float // Your 20% commission totalCost Float // apiCost + commission status String // "pending", "completed", "failed" videoUrl String? createdAt DateTime @default(now()) }

API Endpoints

Get Wallet & Transaction History

GET /api/wallet?userId={userId}
Returns wallet balance and transaction history (last 50 transactions)

Add Funds to Wallet

POST /api/wallet
Body: { userId, amount, description }

Deduct for Video Generation

POST /api/wallet/deduct
Body: { userId, apiCost, videoGenId } — Returns 402 if insufficient balance

Features

  • Prepaid wallet system with persistent user balance
  • Automatic commission calculation (20% configurable)
  • Real-time balance checks before video generation
  • Complete transaction history with timestamps
  • Cost breakdown showing API cost vs commission
  • Insufficient balance detection (HTTP 402 response)
  • Transaction linking to video generations
  • Lifetime spending analytics (totalAdded, totalSpent)
  • Refund support for failed generations
  • Responsive wallet UI component
