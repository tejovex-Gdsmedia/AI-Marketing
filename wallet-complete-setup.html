📊 System Overview

💡 Commission Rate: 20% on all video generation costs (configurable in wallet-service-supabase.ts)

User Flow

  1. User clicks "💳 Add Funds" in Wallet section
  2. Enters amount (e.g., $100)
  3. Funds added to wallet (via payment gateway later)
  4. User generates videos
  5. Cost deducted automatically (API + 20% commission)
  6. Transaction recorded with breakdown
  7. User sees updated balance and history

Cost Example

Generating 10-second Kling 3.0 video:

API Cost: $0.10/sec × 10 = $1.00 Commission: $1.00 × 20% = $0.20 ───────────────────────────────────── Total Cost: $1.20 (deducted from wallet)

💡 Benefits of Wallet System

  • ✅ No repeated bank payments — users prepay once
  • ✅ Faster generation — no payment step per video
  • ✅ Complete tracking — all spending visible
  • ✅ Cost transparency — API cost vs commission shown
  • ✅ Better UX — balance always ready for generation
  • ✅ Business analytics — track user spending patterns
  • ✅ Cloud database — Supabase reliability

🔒 Security

Row Level Security (RLS) policies configured:

  • Users can only see their own wallet and transactions
  • Service role can manage all (backend only)
  • Indexes optimized for fast queries
  • Balance checks prevent overspending
